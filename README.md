# Application Development and Infrastructure

This application is intended to help developers build, test, execute, and deploy applications through repeatable workspaces and shared infrastructure. It provides a foundation for coordinating development work, running isolated workloads, and publishing application changes.

## Objectives
- Provide reusable workspaces and services for application development.
- Run code and development tasks in controlled execution environments.
- Build and deploy application changes with visible progress and results.

## Representative workflow
A developer begins a change in a project workspace, updates the application, and runs the required development tasks in an isolated environment. After reviewing the results and resolving failures, the developer starts a build and deployment, follows its progress, and checks the resulting application.
